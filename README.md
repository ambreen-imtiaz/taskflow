# ⚡ TaskFlow Pro

A modern, fast, and highly customizable personal productivity dashboard designed to help you organize tasks, manage priorities, and track daily goals with ease.

---

## 🌟 Project Purpose

**TaskFlow Pro** is an all-in-one task management workspace built to replace overly complicated productivity tools. Whether you need to manage daily personal errands, track team projects, or visualize work using an interactive Kanban board, TaskFlow Pro keeps your workflow organized, colorful, and completely private. All data is persisted client-side for maximum user privacy.

---

## ✨ Key Features

* **Executive Command Center:** Live clock, productivity reminders, and dynamic metric cards.
* **Interactive Kanban Board:** Drag-and-drop task workflow across *To Do*, *In Progress*, and *Completed* stages.
* **Custom Themes:** Preset and user-defined color themes built with CSS variables.
* **Data Privacy:** 100% local browser storage with JSON backup support.

---

## 🛠️ Tools & Libraries

* **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 (Flexbox & Grid).
* **Styling & Icons:** Modern CSS custom properties and responsive layout architectures.
* **Hosting & Deployment:** Firebase Hosting.
* **Testing & Quality Assurance:** `pytest` for unit testing, `flake8` for code linting and style enforcement.
* **CI/CD:** GitHub Actions automation pipeline.
