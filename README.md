# TaskFlow - Task Management System

TaskFlow is a python-based task management system paired with a static web interface, developed following modern Software Development Lifecycle (SDLC) and CI/CD best practices.

## Features
- **Python Domain Engine:** Core task logic with JSON persistence.
- **Unit Testing:** Automated unit tests covering task operations using PyTest.
- **Static Code Analysis:** Code linting following PEP8 standards with Flake8.
- **Continuous Integration:** GitHub Actions pipeline automated on push and pull requests.
- **Web UI:** Static front-end hosted live via Firebase Hosting.

## Tech Stack
- **Language:** Python 3.x, HTML/CSS/JavaScript
- **Testing & Linting:** PyTest, Flake8
- **CI/CD:** GitHub Actions
- **Hosting:** Firebase Hosting
